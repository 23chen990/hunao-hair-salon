# 叠孔通路｜120 分钟抛弃式灰盒

```text
QUESTION:     陌生玩家能否在无文字静默示例后 30 秒内故意平移薄片并放珠验证，且愿意连续再做至少 5 局？
CORE VERB:    SHIFT（平移整层）
THROWAWAY?:   yes；任何后续产品实现必须重写，不能把本目录提升为正式工程。
TIMEBOX:      120min；到时停止扩项并记录真实缺口。
KEEP IF:      机器硬门槛全部通过，并且之后的陌生真人门槛也通过。
KILL IF:      任一机器硬门槛在一次修复后仍失败，或真人暴露出规则不可理解、像素解、乱移常过、奖励价值靠造坏局等问题。
```

本灰盒只回答机器能回答的技术问题：`SHIFT` 规则是否正确、可生成、可求解、可确定回放、具有普通触控容差，并能形成不请求广告的资格结构。机器测试不能证明好玩、留存、自然需求、广告观看率或收益；没有陌生真人时不得作产品 `KEEP`。

**最终人玩结论（2026-08-11）：KILL。** 用户持续游玩只是为了等待难度出现，但难度始终没有形成；这不是“主动再来一局”的正向信号。每层可独立对孔、首次阻挡直接暴露下一步，BFS 步数衡量的是拖动距离而非决策深度。不得用更多层、更小容差、美术或 Meta 抢救，本目录只保留为可抛弃实验记录。

## 边界

- 只用 Canvas 几何与系统字体；3–4 张半透明薄片、离散横移槽位、圆孔遮罩。
- 逻辑状态是唯一真相；渲染只读取状态。
- 包含 seeded 反向生成、BFS、状态序列化、确定性回放、事件日志和本地资格模拟。
- 不含正式美术、Meta、账号、网络、统计、广告、支付、分享或平台 SDK。
- 不复用《相位涟漪》或任何现成游戏的玩法代码、素材、关卡、名称、UI、数值或商店内容。

## 启动与验证

试玩不需要 Node 或本地服务器：直接双击 `index.html`。如果页面先前已经打开为空白，请按 `⌘⇧R` 强制刷新，或关闭标签后重新双击。

开发验证使用 Node.js 24（本机使用 v24.14.0）。如需重新生成直开 bundle：

```bash
npm run build
```

也可以通过任意静态服务器打开。默认所有广告占位关闭；URL 加 `?eligibility=1` 只会开启本地资格假按钮，不请求广告或网络。

操作只有四项：横向拖动任一 `L1–L4` 薄片并吸附、`放珠`、失败后`免费重试 · 保留布局`、通过后`下一基础 seed`；`重置`恢复当前 seed 的初始布局。

完整验证命令：

```bash
npm test
npm run build
npm run audit
npm run evidence
npm run browser:smoke
```

`npm run verify` 串行执行测试、构建、审计与浏览器烟测。子任务沙箱最初无法启动 Chromium；主任务回收时已在获准的沙箱外环境独立完成双视口烟测。八项机器门槛全绿，但 2026-08-11 的真实人玩反馈确认核心循环始终没有形成难度，最终结论为 `KILL`；详情见 `REPORT.md`。

## 实现结构

- `src/model.js`：唯一玩法真相；反向生成、离散移动、几何逐层放珠、免费重试、规范序列化和哈希。
- `src/solver.js`：只读取模型规则的 BFS/枚举器。
- `src/replay.js`：逻辑时钟事件日志、逐事件状态哈希和确定性回放。
- `src/eligibility.js`：插屏、提示、诊断资格与广告模拟暂停；无 SDK。
- `src/simulation.js`：局长、10,000 随机布局及 10,000 新手代理样本。
- `src/app.js`：Canvas 圆孔遮罩、鼠标/触控 PointerEvent、吸附和只读渲染。
- `tools/audit.mjs`：500 seed 全量门槛与 IAA/无广告回归。
- `tools/browser-smoke.mjs`：390×844 鼠标与 430×932 触控烟测；需允许本地 Chromium。
- `evidence/stacked-aperture-model-frame-390x844.png`：由真实 seed、BFS 近解和真实首次阻挡结果生成的模型帧；明确不是浏览器截图。

最终证据与真实数字见 `REPORT.md` 和 `evidence/`。
