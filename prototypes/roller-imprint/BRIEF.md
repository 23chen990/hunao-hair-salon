# P2 滚筒成章｜120 分钟抛弃式灰盒

```text
QUESTION:   新玩家能否在 30 秒内理解“拖多远就转多少、凸纹会落印”，并从一次错印中主动调整下一趟滚压，而不是把结果当随机动画？
CORE VERB:  ROLL
THROWAWAY:  yes
TIMEBOX:    120min
```

只验证滚动距离、8 面离散转角与落印之间的因果可读性。实现可随实验删除；即使技术门槛全部通过，也必须重写才能进入正式工程。

机器通过后的唯一允许结论是“技术通过，等待陌生真人，产品未决”。没有陌生真人，不能声称 KEEP、好玩、留存或收益成立。

## 抛弃边界

- 真实：8 面滚筒、8×12 二值带、前后滚压、整趟撤销、免费重开、seed、日志/回放、生成/求解与 Canvas PointerEvent。
- 假：接触弧提示、单趟撤销奖励与插屏只计算本地资格；默认关闭，不包含 SDK，也不发送请求。
- 不做：正式 UI、美术、声音、Meta、账号、网络、统计、广告/支付/分享或平台接入。

## 判定

- 任一玩法/实现硬门槛聚焦修复一次后仍失败：`KILL`。
- 浏览器或权限基础设施不可用：对应项记 `ENVIRONMENT_UNVERIFIED`，不能写成机制失败。
- 全部机器门槛通过：`技术通过，等待陌生真人，产品未决`。
