# 《呼吸桥》抛弃式灰盒报告

## 结论

新版已经从“一关一个静态障碍”改为“自动前进 + 桥面边走边长 + 松开跳跃 + 成功解锁下一关”。正式机器审计全部通过：`TECHNICAL_PASS / PRODUCT_UNDECIDED`。这不是产品 KEEP，也不证明好玩、留存或收益；下一步仍需要陌生真人无文字托起测试。

## 机制重构

- 每个 seed 生成 9 个连续段、平台、缺口、矩形障碍和一个终点；桥头由 10 个固定步弹簧节点组成。
- 按住提高压力并让 `bridgeFront` 增长；松开记录输入并把压力转成跳跃脉冲；落地后自动巡航继续。
- `long-reach / short-pulse / high-lift / late-drop / zigzag-rhythm` 是动作语法，不是仅换颜色或坐标。
- 浏览器通过 `?level=N` 复现 seed；成功结算才开放“下一关 →”，任何状态都能免费重开。

## 广告关闭、暂停恢复与环境边界

- `adsEnabled=false`、`networkAllowed=false`、请求预算 `0`、实际请求 `0`。
- 暂停 30–60 秒代理：物理 tick 冻结 `1/1`、哈希契约 `1/1`、输入释放 `1/1`、倒计时损失 `0s`。
- 浏览器烟测脚本会正常重试一次；若 Playwright、浏览器或回环端口仍被宿主阻断，应写 `ENVIRONMENT_UNVERIFIED`。不得绕过权限、伪造数据或把环境故障写成玩法 KILL。
- `artifacts/smoke-390x844-mouse.png`、`artifacts/smoke-430x932-touch.png` 是上一版浏览器复验产物；本次源码改为连续关卡后，应在允许环境中重新运行 `npm run build && npm run smoke` 才能把它们更新为本版证据。

## 假设边界与不能外推

- 随机基线是明确的本地无技能模型：初始随机延迟后，以 `0.25–1.5s` 的随机按住/松开窗反复切换；不代表真人分布。
- 稳健性对每个输入事件施加独立 ±5% 时序噪声，共 25 次/seed；证明的是这套代理窗口，不是所有设备延迟。
- seed 先按动作语法反生成内容；已知策略失败才进入离散束搜索。这证明本批内容有路径，不证明内容丰富度。
- 水平移动是受控巡航代理；本次问题集中在膜形变、桥头增长、释放跳跃和连续落点，不是完整刚体模拟。
- 没有陌生真人，所以不能回答因果是否一眼可读、失败是否归因自己、是否愿意主动再试。
