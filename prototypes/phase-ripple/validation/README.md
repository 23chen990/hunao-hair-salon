# 《相位涟漪》低成本外部可读性验证包

本目录只回答一个问题：陌生人看完一段无声真实玩法后，能否理解“点击位置与时机决定涟漪触发顺序，目标是让棋子同步归心”，并愿意进入试玩、开始第二局。

它不是上线包，也不是市场成绩。所有视频均来自现有灰盒的真实 Canvas 输入与规则结果；没有新增玩法、答案点、改写 seed、伪造成功、音乐或收益承诺。

## 预注册指标

每次记录平台当时显示的原始分母与定义，不把不同口径混算。

### 1. 静音看完率

```text
静音看完率 = 完整播放次数 / 符合平台口径的有效播放开始次数
```

所有素材保持静音，不追加版权音乐或热门音频。平台口径变化时，记录口径和日期；不同口径之间不直接比较。

### 2. 评论能否复述规则

只统计确实尝试解释玩法的独立评论；“好玩”“看不懂”“再来一个”不进入复述分母。盲评标准：

- 正确：同时提到涟漪/距离在安排先后，并提到同步回中心的目标。
- 部分正确：只说“让它们回来”或“点一下”，没有说明先后/同步。
- 错误：认为是连续点击、躲红圈、随机消除或其他不存在的规则。

```text
正确复述率 = 正确复述评论数 / 尝试解释规则的独立评论数
```

保存匿名计数，不在本目录保存账号昵称、头像、手机号等个人信息。

### 3. 进入试玩

只有日后存在合规、可访问的试玩入口时才测：

```text
试玩进入率 = 实际进入试玩的独立用户 / 确实看到有效试玩入口的独立用户
```

主页访问、点赞和“想玩”评论不能冒充试玩进入。当前验证包没有线上试玩入口，因此本项现在为“未测”，不是 0%。

### 4. 第二局意愿

优先使用真实行为：首局得到结果后发生 `retry` 或 `next_level`。若以后接入合规匿名事件，定义为：

```text
第二局启动率 = 首次结果后实际开始第二局的独立用户 / 得到首次结果的独立用户
```

口头表示“愿意再玩”只能作为定性备注，不能替代第二局启动。

## 样本门槛与停损

以下是本项目的预注册规则，不是行业平均或收益保证。

### 小样本保护

- 单条少于 `200` 次有效播放开始：不排序、不判断素材输赢，只记录明显误解。
- 尝试解释规则的独立评论少于 `20` 条：不计算稳定的正确复述结论。
- 实际进入试玩少于 `100` 人：不判断第二局意愿。
- 未达到约 `500` 名同渠道真实新增前，不做产品 KEEP / ITERATE / KILL；约 `1000` 名后才决定是否继续投入，并结合 95% 置信区间。
- 十几个人、一个高赞评论或一条偶然高播放都不能证明市场成立。

### 素材级方向门槛

在同一对照组的每条都达到至少 `300` 次有效播放开始后：

- 看完率差小于 `5` 个百分点：视为持平。
- 差 `5–9.9` 个百分点：只记为方向，需下一轮复核。
- 差至少 `10` 个百分点，且两次相隔 12 小时的快照方向一致：保留较强表达，停止较弱表达。
- 正确复述率在至少 20 条解释评论下达到 `70%`：可读性方向通过；`50–69%` 只迭代一个表达变量；低于 `50%` 停止该素材表达，不据此直接判死游戏。

若有有效试玩入口且至少 200 名用户看到入口：试玩进入率 `>=8%` 为绿色方向，`3–7.9%` 为 ITERATE，`<3%` 停止该素材入口。它是项目停损线，不是市场承诺。

若至少 100 名试玩者得到首个结果：第二局启动率 `>=35%` 为绿色方向，`20–34%` 为 ITERATE，`<20%` 停止继续扩大这轮测试；正式产品判断仍等待约 500 名同渠道新增。

### 零投放停损

- 7 条都发完、每条观察至少 48 小时后，如果任一关键对照仍未达到分母门槛，结论是“自然分发样本不足”，不是“玩法失败”。停止继续制作同类素材，不付费补量，等待新的自然样本或用户另行决策。
- 任意步骤要求现金支出，现金停损立即触发：本轮预算为 `0 元`。
- 不因看完率低就加长文字教程、答案点、音乐、抽奖、收益暗示或不存在的玩法。
- 若达到充分样本后，正确复述与第二局启动同时低于停损线，停止外部扩大；回到一次单参数 ITERATE 或按主计划 KILL，不用美术和 Meta 抢救。

## 最小人工可读性关

正式建 Cocos 工程前，仍应执行决策记录中的无讲解测试：至少 5 名不熟悉规则的玩家中，4 名能在第三次尝试前有目的地改变点击位置，3 名主动连续玩 5 个 seed。达不到时不因视频数据偶然好看而进入正式开发。

## 本地复现与验收

本流程直接打开本机 `file://` 原型，不绑定端口、不联网。需要本机已有 Playwright/Chromium、Python OpenCV 和 Pillow。

```bash
cd /Users/kker/Documents/ChatGPT/game2/prototypes/phase-ripple

node --test validation/tests/*.test.mjs
python3 -m unittest validation/tests/media_tools_test.py
node validation/capture.mjs
python3 validation/encode.py
python3 validation/verify.py
```

若 Playwright 不在脚本列出的本机路径，可只提供模块入口，不安装依赖：

```bash
PHASE_RIPPLE_PLAYWRIGHT=/absolute/path/to/playwright/index.mjs node validation/capture.mjs
```

本机没有 `ffprobe`。Playwright 自带的 `ffmpeg-mac` 已实际对连续 WebM执行 `-i`，确认 VP8、390×844、25 fps 且只有视频流；但该定制版只启用了 WebM/image2 demuxer，不能解析最终 MP4。最终 MP4 因此由 OpenCV 的 FFmpeg 后端验证 H.264、尺寸、帧率和时长，由 `file` 验证 MP4 容器，由 `afinfo` 确认没有可读音轨。这个限制已写入 `evidence/verification-report.json`，不得把它描述成“ffprobe 已通过”。

本流程没有登录、发布、建号、联网发消息、付款、投放或提交审核。
