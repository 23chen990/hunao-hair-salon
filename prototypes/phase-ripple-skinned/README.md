# 《相位涟漪》桌面磁力玩具可玩切片

这是一个零依赖 TypeScript + Canvas 浏览器切片，不是正式 Cocos 工程。它复用已验证的“一次点击产生空间涟漪，依距离让外逃棋子折返并同步归心”规则，只验证低成本位图皮肤能否提升外部可读性。

## 直接运行

仓库包含已构建的浏览器 ESM，不需要安装依赖：

```bash
cd /Users/kker/Documents/ChatGPT/game2/prototypes/phase-ripple-skinned
python3 -m http.server 4188 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4188/>。教学不再用规则卡解释：第一课只有 1 枚棋子，亲手看到“碰到 → 掉头 → 回中心”；第二课只有 2 枚棋子，第 ①、② 次碰撞会分别冻结，最后展示“先后掉头 → 同时到家”。完成后才进入 3–6 枚棋子的正式玩法。每个完整关卡由 3 个短回合组成；失败页提供“再试一次”和“看落点提示”两个明确选择，后者只作为奖励视频意愿节点记录，目前不接广告 SDK。

## 实现边界

- 规则、生成器、求解器、20 seed、固定步长和本地事件日志保持与已验证灰盒一致。
- 静态底板是独立生成的 853×1844 位图；没有棋子、轨迹、涟漪或烧入文字。
- 外逃棋子和已折返棋子是分别生成、去背并检查透明边缘的独立 RGBA 位图，可按规则角度旋转。
- 棋子坐标/旋转、方向轨迹、点击原点、涟漪半径、同步窗口、结果反馈和全部文字由 Canvas 实时渲染。
- 没有 Meta、商城、广告、账号、联网、第二玩法、平台 SDK 或外部消息。

## 已知偏差

- 生成底板的圆盘在竖向略显拉长，实时规则因此使用盘内安全圆，而不是把生成图像的椭圆轮廓当作碰撞数据。
- 底板边角含茶碗、纸张和植物装饰，气氛完整但可能在小屏上略抢注意力；外部可读性测试若出现视线游离，应只迭代这一层。
- 两枚棋子分别生成，返回态多一圈青绿釉边，形状与外逃态不是严格像素同模；当前有利于非颜色状态区分，但正式生产应做同模人工校正。
- 成功时规则层的所有棋子都真实到达半径 0，因此位图会重叠在中心；没有为了状态稿的“可数四颗”而伪造棋子位置。

## 技术 KEEP / ITERATE / KILL

**技术结论：KEEP。** 皮肤切片没有改变核心规则，位图确实进入实时 Canvas，双视口、真实输入、重试、下一关、确定性、求解和日志全部通过。

- **KEEP**：把本切片用于下一轮无讲解、静音外部可读性验证；保留一次点击和当前规则参数。
- **ITERATE**：若玩家看不出“点击位置决定触发顺序”，一次只调底板装饰密度、轨迹形状或成功中心重叠的表现，不能同时改规则与美术。
- **KILL**：若皮肤后仍需长文字/答案点才能理解，或玩家主要乱点且不愿立即重试，不增加 Meta、养成或第二玩法抢救，也不建立正式 Cocos 工程。
