# 第六阶段验收说明

本阶段只实现洗、剪、吹、多步骤订单、工位流转、后台任务和快速毛巾过渡；没有加入染发、烫发、毛巾库存、洗衣机或后续 Day 系统。

## 核心操作

1. 点击等待顾客，再点击合法空闲工位完成安排。
2. 洗头床：点同一个花洒并长按头部完成打湿；点洗发水后长按揉洗起泡；再点花洒长按冲净；最后单击毛巾快速收尾。
3. 理发椅：毛巾包头顾客必须先选择“拆毛巾”并快速长按。CUT 再按原三工具长按操作；BLOW 点击启动后可离开，回来点击结束。
4. 订单气泡始终只有一组；完成步骤显示勾，当前步骤高亮。包/拆毛巾不会成为订单图标。
5. 完整订单完成后只掉落一份金币，并仍需手动拾取。

## 默认可调参数

| 参数 | 默认值 |
|---|---:|
| 花洒打湿 | 与冲洗共用同一工具与时长配置 |
| 上洗发水 | 2.0 秒 |
| 揉洗起泡 | 2.0 秒，完成后立即可冲洗 |
| 冲洗 | 2.0 秒 |
| 包毛巾 | 0.65 秒 |
| 拆毛巾 | 0.55 秒 |
| 吹发最佳窗口 | 5～7 秒 |
| 吹发轻度超时 | 7～10 秒 |
| 吹发严重超时 | 10 秒以上 |
| 默认营业时间 | 180 秒（可配置） |

## 自动化综合场景

`Phase6ServiceChainTests.WashAndBlowBackgroundWorkContinuesDuringAnotherHaircut` 同时建立：A 在洗头床等待冲洗、C 在理发椅后台吹发、B 正在主动剪发、D 留在等待区。测试确认 B 的主动操作期间世界时间仍推进、C 进入最佳窗口、D 进入蓝色汗滴对应的不耐烦状态，且洗头床保持占用。

工位不负责锁定服务顺序：洗发或剪发未完成时，顾客仍可被带到任意可用的 V1 工位；洗发阶段、泡沫计时、毛巾和剪发进度保存在顾客模型上，不因离开工位而重置。仅正在执行的长按操作和明确运行中的自动吹发设备暂时锁定移动，动作结束或取消后立即恢复。

工具栏由工位能力决定：洗发工位固定提供打湿、洗发液、冲洗、包毛巾；理发工位固定提供拆毛巾、剪刀、分齿剪、推子。需求只用于完成评价，错误或重复服务允许真实执行并产生耗时、占位和满意度成本。毛巾未拆、洗发液未冲净等物理阻塞会阻止剪发或最终结算，但不会阻止顾客移动。
