# 第三阶段 Demo 验收清单（无需懂代码）

## 打开 Demo

1. 在 Finder 打开项目目录里的 `Builds` 文件夹。
2. 双击 `HairSalonDemo.app`。
3. 如果 macOS 提示无法打开，请右键应用，选择“打开”，再确认一次。
4. 每次想测试另一种结果时，可以关闭并重新打开 Demo，最容易观察。

进入游戏后先等约 2 秒。顾客会自己走到两个剪发工位；点击坐在剪发椅上的顾客即可开始。

## 先认识画面

- 顾客头顶气泡：剪发需求，可能一步，也可能两步。
- 底部三个按钮：剪刀、分齿剪、推子。
- 顶部数字：当前金币余额，初始为 8,640。
- 按住顾客时，只看当前需求的视觉进度，不会显示秒数。

## 1. 验收 PERFECT

1. 看头顶气泡，选择气泡当前高亮的工具。
2. 在顾客身上按住一小会儿，在进入合适区域后松开。
3. 如果是两步需求，第一步出现勾后，选择第二个工具并重复。
4. 预期：显示 `PERFECT · 300 金币`，工位旁出现标注 300 的大金币堆。
5. 此时顶部仍应为 8,640；点击金币堆，金币飞向顶部后变为 8,940。

体验时可用的大致节奏：剪刀约 1.5～2.5 秒，分齿剪约 1.45～2.1 秒，推子约 0.7～1.45 秒。游戏内不会显示这些数字。

## 2. 验收 UNDERCUT 与 RECOVERED

1. 选择正确工具，只短按一下就松开。
2. 预期：提示剪得不够，当前步骤没有打勾，顾客轻微不满意，仍可继续。
3. 再用正确工具完成全部步骤。
4. 预期：最终显示 `RECOVERED · 120 金币`，出现中金币堆；未点击前余额不变，点击并飞完后增加 120。

## 3. 验收 OVERCUT

1. 选择正确工具后一直按住顾客，不要松开。
2. 预期：超过危险区后立即提示剪太短，不需要松开鼠标；顾客生气，服务评为 `FAILED`。
3. 工位旁不出现金币堆，顶部余额不变；顾客显示不满意反馈后离店，工位恢复空闲。

## 4. 验收 WRONG_TOOL

1. 故意点击一个与头顶当前需求不同的工具。
2. 先不要按顾客。预期：只切换工具，不扣分、不失败。
3. 再在顾客身上开始按住。
4. 预期：立即提示工具错误，顾客生气，服务评为 `FAILED`；不出现金币堆，余额不变。

## 5. 验收世界与工位

1. 操作剪发时观察顶部时间和其他顾客：它们应继续变化或移动，世界不会暂停。
2. 服务结束后顾客会离店，剪发椅可接待下一位顾客。
3. 成功服务即使暂时不点击金币堆，也不会卡住顾客离店或工位恢复；失败服务不会生成金币。
4. 点击地面空白可回总览；不会进入新的剪发页面，也不会改变原镜头布局。

以上五组都符合，即可认为第三阶段验收通过。
