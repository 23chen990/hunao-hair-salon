# 第二轮统一评分卡

> 评分日期：2026-08-10。分数是研究者判断，不是市场数据。总分只用于排灰盒先后；IAA 一票否决、禁做品类和组合去重优先于总分。

## 1. 评分口径

九项均为 0–5 分，总分 45 分：

| 缩写 | 指标 | 5 分含义 | 0–2 分警报 |
|---|---|---|---|
| 懂 | 10 秒可懂 | 无文字或一次静默演示即能故意完成核心动词 | 需要规则说明、隐藏状态或多步教学 |
| 人 | 个人范围 | 单人低现金可做，核心实现与内容维护轻 | 依赖大量美术、手工关、服务端或团队 |
| 验 | 自动验证 | 可用求解器、仿真、属性测试与确定性回放排坏局 | 主要靠人工感觉/语义内容 |
| 供 | 内容供给 | 由少量参数稳定生成、可长期筛坏局 | 依赖手工剧情、关卡、美术或每周制作 |
| 传 | 传播画面 | 6–12 秒内有清晰前后反转/险过画面 | 静态难懂、过程无视觉转折 |
| 商 | 商业兼容 | IAA-first、无服务器/内购也能有自然价值节点 | 只有 Banner、强制广告或付费经济才成立 |
| 反买 | 买量依赖反向分 | 估计可由可读画面、搜索/复访和产品本身获得验证，较不依赖付费 UA | 所在子类高度买量化/存量巨头化；5 分也不代表已有自然流量证据 |
| 库 | IAA 库存与会话深度 | 自然会话约 8–12 分钟，有两类真实自愿奖励位和 1–2 个低频自然插屏断点 | 只能靠短局强插、单一续关或 Banner |
| 伤 | 广告不伤体验 | 去广告玩法完整，加入低频合规广告仍不打断核心心流 | 广告打断节奏/顿悟/放松，或靠假难度逼看 |

`库 < 3` 或 `伤 < 3` 的候选不论总分多高都不得进入前三。买量反向分是风险判断，不是自然下载归因；公开网页未提供完整买量占比时，不做精确归因。

## 4. 淘汰与保留理由

| ID | 决策理由 |
|---|---|
| C01 | 最高自动验证能力、内容可逆向生成、会话能组成 6–9 个自然局；先做机器正确性淘汰最便宜。主要未知是层叠画面是否 10 秒可懂。 |
| C02 | 视觉前后反转最强，滚压与撤销形成两种自然奖励价值；排名第二是因为圆柱转角映射可能需要教学，且满足类美术预期较高。 |
| C03 | 软体险过画面强，真实检查点能形成不虚假的续行价值；排名第三是因为低端机确定性和手感风险高于前两名。 |
| C04 | 39 分且 IAA 过门槛，但“左减右增”的隐含规则比前三更难解释，视觉也与擦除/DOP 相邻；作为候补，不扩大本轮队列。 |
| C05 | CSP 自动化与会话都好，但需求母题与现有座位/空间约束作品太近，裸抽象版又可能失去角色魅力；不承担 IP/同质化灰区。 |
| C06 | 视觉强但连续拖光没有足够自然失败/结算断点，IAA 库存 2 分，硬淘汰。 |
| C07 | 可做、可测、可拍，但切割/画线物理簇拥挤且买量依赖风险高；3 分广告伤害只是临界，不值得占前三。 |
| C08 | 折叠规则成熟、同质化/IP 搜索风险高，且短局要维持低频广告较困难。 |
| C09 | 一挡板机制可模拟，但粒子碰撞跨设备一致性与既有弹球观感同时削弱个人优势。 |

## 5. 组合选择说明

前三分别是“移动整层、滚动工具、连续形变”，输入—状态—结果都不同：

- C01 是离散空间状态，可先机器穷举正确性；
- C02 是离散滚动/覆盖序列，强调可逆图案生成；
- C03 是连续控制与简化物理，强调手感和容错。

没有因为 C04/C05 分数接近就扩成五个原型。第二轮目标是降低不确定性，不是囤积半成品；每张卡仍必须在真人测试后单独决定 KEEP/KILL。
