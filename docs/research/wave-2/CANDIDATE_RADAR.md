# 第二轮候选雷达

> 截止日期：2026-08-10（Asia/Shanghai）  
> 性质：研究与灰盒立项；不是产品承诺、收益预测或第二款正式游戏决定。  
> 临时中文名仅为讨论标签，未做商标检索。任何原型只验证抽象核心动词，不复用被观察产品的代码、美术、UI、关卡、角色、名称、数值或商店素材。

## 0. 先说结论

本轮共保留 16 个可讨论机制进入统一评分，最终只把三个不同核心动词送入灰盒队列：

1. **叠孔通路** — `SHIFT / 平移整层`
2. **滚筒成章** — `ROLL / 滚压`
3. **呼吸桥** — `INFLATE / 充放形变`

《相位涟漪》不在本轮候选中，也没有被改题材、换皮或扩写成第二款。前三名只是下一次抛弃式实验的排序；机器通过只能排除错误机制，不能证明好玩、留存或广告收入。

## 1. 证据与推断边界

候选使用两种标签：

- **市场事实衍生**：近期至少有一个跨产品需求簇可观察；只抽象“满足、修复、物理预测、单手控制”等需求母题，不照搬玩法实现。
- **创意推断**：来自机制组合与可验证性推导，当前没有足够公开数据证明自然需求。进入灰盒的目的正是便宜地证伪。

市场事实、产品簇和直接链接集中在 [SOURCES.md](./SOURCES.md)。公开网页没有提供每个产品连续 12 周的完整自然下载、留存、广告收入和买量占比，因此本文采用 **2026-05-18 至 2026-08-09 的 12 周观察窗 + 2026-08-10 终点快照**：看独立发行方数量、期间更新、当前规模、近期评论与分析机构的子类变化。它是雷达代理，不冒充周榜面板或自然需求证明。

## 2. IAA 一票否决规则

以下不是加分项，而是进入前三的必要条件：

1. 不把 Banner 算进可持续性；必须有至少两个与真实玩法价值一致、由用户主动选择的奖励广告场景。
2. 广告全部移除后，基础关卡、免费重试与正常进度仍成立；不得以人为制造的体力、倒计时、坏局或假难度逼看广告。
3. 首三局不展示插屏；之后只在结算页的自然停顿、且不早于会话约 180 秒。设计上同两次插屏间隔 **180–300 秒**，并遵守奖励广告后至少 60 秒再插屏的抖音能力限制；绝不每局强插。
4. 合规低频广告加入后，核心节奏仍应成立。若只能把插屏提高到每局或约每分钟一次才能接近任何日净目标，直接淘汰。
5. `IAA 库存与会话深度`、`广告不伤体验`两项评分任一低于 3，不得进入前三。

本文所有“每会话广告位、会话长度、日会话次数、提示/续关概率”都是**待真人验证的设计假设**，不是留存、填充率、eCPM、ARPDAU 或收益承诺。当前没有日净目标、真人行为、渠道流量和地区广告价格，不能做收入反推。

### 共用无广告基线

- 无限免费重开当前关；不看广告也能切换到另一基础种子。
- 失败不扣体力、不倒退已完成进度；基础难度由求解器与容错阈值控制。
- 奖励入口只有在“确实卡住、发生真实失误、完成后想追加挑战”时出现，不默认选中，不遮挡“不看”。
- 低端 Android 灰盒预算：竖屏 Canvas、固定步长、少量几何体、无大纹理、无持续网络；后续真实原型以 2 GB RAM 档设备为最低验证档，而不是宣称该人群一定喜欢。
- 40+ 只作为可访问性观察：大触区、高对比、少文字、无高频多指操作；公开资料不足以证明这些机制天然适配 40+，不硬贴标签。

## 3. 候选详表

### C01 叠孔通路 — 第一名

- **来源类型**：创意推断；借用了“从混乱到瞬间贯通”的需求母题，没有直接市场需求证明。
- **一句话**：左右平移 3–4 张带孔透明薄片，让孔洞重叠成一条完整通路，再放下一颗珠子验证。
- **核心动词**：`SHIFT`，平移整层；不是逐格连管、箭头移动或《相位涟漪》的时机点击。
- **30–90 秒循环**：看 2 秒自动失败示例 → 单指拖动各层 → 点“放珠” → 珠子通过或在阻挡层停下 → 保留布局继续调整；目标局长 45–75 秒。
- **自然内容钩子**：杂乱半透明孔洞在最后一次拖动后“咔哒”对齐，珠子一镜到底穿过；失败时珠子明确卡在某一层，适合 6–12 秒真假选择或残局短视频。
- **两类自愿奖励位**：① 连续两次验证仍卡住时，看一次广告高亮“下一张该动的层”，不是给答案；② 失败结算可看确定性慢放，标出首次阻挡层并叠加一次路径诊断，免费立即重试仍保留。
- **会话与广告容量（设计假设）**：6–9 局形成 8–12 分钟自然会话；可选奖励位 0–2 次/会话；自然插屏位 1–2 次/会话，仅第 4/8 局后且距上次全屏广告至少 180 秒；可能 1–3 会话/日。前 3 局零插屏。
- **广告健康检查**：无广告时全部基础种子、重试和视觉反馈完整；加入低频广告只占结算/帮助节点。若玩家通常 3 局内离开、或诊断提示没有真实价值，则 IAA 结构不成立，不能靠加插屏补救。
- **程序生成**：先选每层正确偏移，沿纵向刻出一条保证贯通的孔链，再加入不形成第二条直通路的诱饵孔；种子决定层数、偏移域和遮挡顺序。
- **自动验收**：BFS/枚举状态 `(各层偏移, 珠子所处段)`；验证有解、确定性回放一致、随机布局直通率不高、最短解步数处于目标区间、正确偏移有可触摸容差、无死锁种子。
- **两小时 Canvas 灰盒**：3 层、离散横移、圆孔遮罩、单颗珠子、放珠/重置、seed HUD、一个离线枚举器；不做美术、地图、元循环或广告 SDK。
- **同质化/IP 风险**：中低；必须避免管线、箭头、停车位视觉和任何现成关卡布局。临时名未检索。
- **为什么可能已经太晚**：抽象“对齐开孔”可能被玩家理解成老式滑块/管线拼接；如果静态截图无法表达层间关系，短视频钩子会只剩视觉噪声。

### C02 滚筒成章 — 第二名

- **来源类型**：市场事实衍生 + 创意推断；“整理/完成图案”的满足需求在移动与 PC 簇中可见，但滚压机制及商业适配尚无需求证明。
- **一句话**：拖动带有凸纹的滚筒，在短色带上滚压，利用起始角度与来回路径印出目标图案。
- **核心动词**：`ROLL`，滚压；拖动距离决定圆柱转角，不是 Sort、三消或方块填盘。
- **30–90 秒循环**：看目标二值图 → 调起始角 → 单指滚过 2–4 条轨迹 → 对比覆盖/漏印 → 撤销或提交；目标局长 45–80 秒。
- **自然内容钩子**：看似错误的花纹滚过空白带后恰好显出图案；一次越界造成“多印一格”的清晰反转，天然适合慢放和评论区猜路径。
- **两类自愿奖励位**：① 卡住时显示下一段安全接触弧与方向；② 最后一趟多印/漏印时恢复到上一趟滚压前，免费全局重开仍在。
- **会话与广告容量（设计假设）**：5–8 局、7–11 分钟；可选奖励位 0–2 次/会话；自然插屏位 1–2 次，只在第 4 局后或一组图案完成后，间隔 180–300 秒；可能 1–3 会话/日。
- **广告健康检查**：无广告可无限撤销整局和重开；奖励只减少重做一趟的时间。若基础局平均低于 35 秒或撤销广告变成事实必需，淘汰。
- **程序生成**：从一串合法滚动动作反向渲染目标，再加入不改变可解性的空轨和起始角候选；离散化圆柱周长、花纹位和带格。
- **自动验收**：图搜索/动态规划寻找动作序列；校验目标可达、最短步数、解的容错、重复滚压幂等规则、不同帧率回放一致、随机乱滚命中率。
- **两小时 Canvas 灰盒**：一个 8–12 格色带、8 面滚筒、拖动转角、二值印记、撤销、目标/seed、离散求解器；只用几何块。
- **同质化/IP 风险**：中；不可使用现成印章图、具体工艺包装或相似 UI。需要检索是否已有同规则移动游戏。
- **为什么可能已经太晚**：满足类内容供应拥挤且美术预期高；如果几何灰盒不够“爽”，个人开发者可能被迫进入大量手工图案与质感制作。

### C03 呼吸桥 — 第三名

- **来源类型**：市场事实衍生 + 创意推断；物理预测需求有跨产品规模信号，但“充放膜”控制是待验证创意。
- **一句话**：按住让一张弹性膜鼓起、松开让它回落，用一次连续呼吸般的形变把负载送到终点。
- **核心动词**：`INFLATE`，充气/放气控制形变；不画桥、不造车，也不是相位时点换皮。
- **30–90 秒循环**：观察起点/障碍/终点 → 按住鼓起托举，滑动可轻微移动受力点 → 松开泄压让负载落位 → 成功或跌落；目标局长 40–70 秒。
- **自然内容钩子**：软膜从危险下方鼓起形成临时桥，负载贴边弹过；“差一点掉落又被回弹接住”可形成明显短视频反转。
- **两类自愿奖励位**：① 两次失败后显示一条粗粒度压力幽灵曲线；② 在到达中段检查点后真实跌落，可从检查点复位一次，免费从头重试始终可用。
- **会话与广告容量（设计假设）**：5–8 局、7–10 分钟；可选奖励位 0–2 次；自然插屏位 1 次为主、上限 2 次，只在第 4/8 局结算且间隔至少 180 秒；可能 1–3 会话/日。
- **广告健康检查**：初级关不设倒计时、免费重开即时；检查点只在确有中段进度的关出现。若控制窗口必须被压窄才能触发续关，或低端机帧差改变输赢，淘汰。
- **程序生成**：从可执行的“按住时长/受力点/松开时刻”控制序列正向生成障碍与终点，再扰动几何；只保留具有宽容控制带的种子。
- **自动验收**：固定步长弹簧质点简化模型；束搜索控制序列，验证至少一条稳健路径、成功窗口宽度、随机控制成功率、穿透/爆能量属性、确定性回放。
- **两小时 Canvas 灰盒**：8–12 个膜节点、简化弹簧、单负载、两个矩形障碍、按住/松开、检查点、seed 和离线束搜索；不做真实软体美术。
- **同质化/IP 风险**：中；物理护送与画线救援拥挤，必须坚持“已有膜的连续形变”，不用棒人、蜂群、车辆或现成救援叙事。
- **为什么可能已经太晚**：物理子类收入增长可能主要来自混合变现和老产品优化，而非新增自然受众；移动端软体手感也容易被低帧率毁掉。

### C04 双面余量

- **来源类型**：市场事实衍生 + 创意推断；来自“整理/补全/前后对照”的母题，耦合增减规则无市场证明。
- **一句话**：在左板刮去的每一格会按镜像落到右板，单指移动一块刮片，让两边同时接近各自目标轮廓。
- **核心动词**：`TRANSFER`，转移材料。
- **30–90 秒循环**：看双目标 → 拖动 1–3 次刮片 → 左减右增同步动画 → 比较误差 → 提交；45–75 秒。
- **自然内容钩子**：左边越空、右边越满，最后一次划过让两张相反图同时完成。
- **两类自愿奖励位**：① 高亮一格“该从哪边转”；② 撤销最后一次整段转移，免费重开仍可用。
- **会话与广告容量（设计假设）**：6–8 局、7–10 分钟；奖励位 0–2；插屏位 1 次、最多 2 次，仅第 4/8 局后与全屏广告间隔至少 180 秒；日会话 1–2。
- **广告健康检查**：无广告有完整基础解与免费重开；若玩家必须频繁撤销才能理解规则，说明 10 秒可懂失败而非广告机会。
- **程序生成/自动验收**：从目标差集反推转移动作；位图状态 BFS/IDA* 检查可解、最短步、解唯一性范围、误差单调性和确定性回放。
- **两小时范围**：两个 8×12 位图、镜像转移、3 个笔刷宽度、目标误差和求解器。
- **同质化/IP 风险**：中高；易靠近擦除、DOP、折纸或整理广告素材，必须保持“双板守恒转移”而非现成题型表达。
- **为什么可能已经太晚**：裸几何可能不够有情绪价值，而成熟擦除/补全素材已经占据用户心智；需先以灰盒判断规则理解度。

### C05 相邻避让

- **来源类型**：市场事实衍生；Steam 的舒适空间约束/整理产品显示“把对象放到合适位置”仍有受众，但评价分化说明规则清晰和内容品质决定成败。
- **一句话**：把 5–8 个抽象圆片放入一圈座位，只满足可见的邻近/远离图标约束，不使用角色剧情。
- **核心动词**：`PLACE`，放置关系。
- **30–90 秒循环**：读 2–4 个图形约束 → 拖圆片入位 → 冲突即时显色 → 全部满足完成；45–80 秒。
- **自然内容钩子**：最后挪动一个圆片，连锁消掉全部红色冲突；残局可让观众先猜唯一座位。
- **两类自愿奖励位**：① 指出一条当前冲突的必要条件；② 撤回到上一个无冲突状态，免费任意重排仍成立。
- **会话与广告容量（设计假设）**：5–8 局、8–12 分钟；奖励位 0–2；插屏位 1–2，只在四局一组的结果页，180–300 秒间隔；日会话 1–2。
- **广告健康检查**：帮助只解释已有图标，不能把晦涩图标当广告入口。若语言/图标教学超过 10 秒或抽象版失去舒适吸引力，淘汰。
- **程序生成/自动验收**：先生成合法座次再采样约束；CSP/SAT 枚举解数，控制唯一/多解、冗余条件、最小冲突和无障碍色彩之外的形状编码。
- **两小时范围**：8 个圆片、8 座环、邻近/不邻近/对面三种约束、回溯求解器。
- **同质化/IP 风险**：高；与现有座位/空间约束作品的核心表达距离过近，必须避免角色、场景、偏好文案和关卡结构相似。
- **为什么可能已经太晚**：PC 成功样本依赖角色魅力与手工内容，无法廉价抽象；抽掉这些后可能只剩干燥 CSP，故不进入前三。

### C06 影合轮廓

- **来源类型**：创意推断；近期 PC 的可见性/视角机制只是创意供应信号，不是商业需求证据。
- **一句话**：拖动一个光源，让 2–4 个简单物体投出的影子重叠成目标轮廓。
- **核心动词**：`LIGHT`，移动光源。
- **30–90 秒循环**：看目标影形 → 拖光源 → 实时观察投影 → 误差低于阈值锁定；35–70 秒。
- **自然内容钩子**：杂乱物体的影子在某一角度突然拼成可识别符号，视觉反转强。
- **两类自愿奖励位**：① 给出可行光源区域的模糊热区；② 开启一次物体到影子对应关系的 X 光叠层。
- **会话与广告容量（设计假设）**：5–7 局、5–8 分钟；奖励位 0–2；自然插屏 0–1 次，仅第 4 局后；日会话 1–2。
- **广告健康检查**：无广告可连续试角度；两种帮助都只减少盲试。连续试验本身没有真实失败断点，插屏很容易破坏“顿悟”，因此 IAA 深度预估不足，硬门槛失败。
- **程序生成/自动验收**：从光源解位置生成目标栅格，扰动物体；栅格化搜索误差面，要求可行区不为单像素、局部极小值数量受控、跨分辨率一致。
- **两小时范围**：二维投影近似、3 个矩形/圆、一个光源、目标蒙版、网格搜索。
- **同质化/IP 风险**：中高；影子拼形和透视解谜已有大量作品，目标一旦做成具体角色/IP 轮廓风险更高。
- **为什么可能已经太晚**：强视觉钩子已成熟，且连续顿悟循环缺少可持续 IAA 断点；传播强也未必能商业成立。

### C07 一刀平衡

- **来源类型**：市场事实衍生；物理谜题有规模与变现信号，同时近期评论也显示超短局配高频广告会伤害体验。
- **一句话**：在一个不规则块体上划一刀，让两块落到左右秤盘后同时保持目标重量区间。
- **核心动词**：`CUT`，一次切割。
- **30–90 秒循环**：观察形状/支点 → 拖一条切线 → 两块落下 → 看重量/稳定性 → 重试；40–70 秒。
- **自然内容钩子**：看似歪斜的一刀落下后两侧恰好平衡，或一小角导致整盘翻转。
- **两类自愿奖励位**：① 显示质心容许带而非切线答案；② 失败后恢复切前状态并保留上一刀虚线，免费重开可用。
- **会话与广告容量（设计假设）**：6–9 局、7–10 分钟；奖励位 0–2；插屏 1–2 次，第 4/8 局后、≥180 秒；日会话 1–2。
- **广告健康检查**：不得把切割判定做成像素级来增加续关；若合理手势仍大量边界失败，广告不伤体验分应降到 2 并淘汰。
- **程序生成/自动验收**：从随机多边形与已知切线生成；多边形裁剪 + 质心/简化刚体仿真，检查宽容解带、落盘稳定、随机切命中率。
- **两小时范围**：单多边形、切线、两秤盘、面积质心近似、100 条候选切线扫描。
- **同质化/IP 风险**：高；切割、画线、物理救援都是成熟买量视觉，极易被误认为同质换皮。
- **为什么可能已经太晚**：素材表达和发行竞争已经成熟，个人产品若无买量很难仅靠“一刀平衡”建立新心智。

### C08 对折成形

- **来源类型**：市场事实衍生；满足式图形完成有需求母题，但具体折纸移动玩法已成熟。
- **一句话**：拖动一条折痕把带孔薄片翻折 1–3 次，让重叠轮廓覆盖目标。
- **核心动词**：`FOLD`，折叠。
- **30–90 秒循环**：看目标 → 选折线/方向 → 动画叠合 → 检查覆盖 → 再折或重开；35–65 秒。
- **自然内容钩子**：分散孔洞折叠后组成完整符号，前后画面强。
- **两类自愿奖励位**：① 显示下一条折痕的方向象限；② 撤销最后一折并保留痕迹，免费整局重开。
- **会话与广告容量（设计假设）**：7–10 局、6–9 分钟；奖励位 0–2；插屏 1 次、最多 2 次，第 4/8 局后；日会话 1–2。
- **广告健康检查**：折叠动画期间不插广告；若多数局一次折完导致会话太浅，则失败，不能靠每局插屏。
- **程序生成/自动验收**：从合法折序反生成初始点集；位图变换搜索解数、最短折数、边界容差和无自交异常。
- **两小时范围**：方形纸、水平/垂直/对角有限折线、位图叠合、BFS。
- **同质化/IP 风险**：高；Paper Fold 类规则、折纸画面和广告素材高度成熟，需避免任何现成折序、图案和 UI。
- **为什么可能已经太晚**：自然分发心智已被成熟折叠产品占据，短局又难容低频 IAA；不应进前三。

### C09 反弹描边

- **来源类型**：市场事实衍生 + 创意推断；借物理预测需求，不复制滚球轨道或画线保护。
- **一句话**：拖入一个圆形挡板后发射一串珠子，利用一次反弹把目标边界尽量描亮。
- **核心动词**：`PLACE BUMPER`，放置挡板。
- **30–90 秒循环**：看发射口/轮廓 → 放一个挡板 → 发射 8–20 粒珠 → 覆盖评分 → 调整；40–75 秒。
- **自然内容钩子**：一串珠子扇形散开，沿轮廓连续点亮；差一格与全亮对比强。
- **两类自愿奖励位**：① 显示粗略反弹包络线；② 失败后取回挡板并保留珠子热图，免费重新发射/重开。
- **会话与广告容量（设计假设）**：6–8 局、6–9 分钟；奖励位 0–2；插屏 1 次，第 4 局后；日会话 1–2。
- **广告健康检查**：物理散布不可暗中随机化制造失败；若固定种子也因帧率变化产生结果漂移，淘汰。
- **程序生成/自动验收**：从可行挡板位置正向模拟目标；网格搜索位置/半径，验证覆盖阈值、容差、确定性和性能上限。
- **两小时范围**：圆碰撞、20 粒珠、一个挡板、轨迹热图、位置网格求解。
- **同质化/IP 风险**：中高；Peggle、弹球和滚球视觉非常成熟，碰撞布局与特效都不能借用。
- **为什么可能已经太晚**：如果单挡板决策不能形成新理解，它只会像已有弹球广告的切片，难以自然分发。

### C10 温差配合

- **来源类型**：创意推断；“看材料从不合到严丝合缝”来自满足母题，没有独立需求证据。
- **一句话**：拖动冷热源，让 2–3 根材料伸缩，恰好卡入同一框架。
- **核心动词**：`HEAT/COOL`，调温形变。
- **30–90 秒循环**：观察间隙 → 移动热/冷源或按住加热 → 材料缓慢伸缩 → 在目标区松手锁定；45–80 秒。
- **自然内容钩子**：尺寸不一的杆件逐渐伸缩，最后同时“严丝合缝”卡住。
- **两类自愿奖励位**：① 显示一根材料的目标温区；② 允许一次冻结已正确材料，免费继续调整全部材料仍可行。
- **会话与广告容量（设计假设）**：5–8 局、7–10 分钟；奖励位 0–2；插屏 1 次、最多 2 次，第 4/8 局后；日会话 1–2。
- **广告健康检查**：无广告不能依赖隐藏温度公式；冻结奖励只减认知负担，不应成为多材料必需。若 10 秒演示仍不懂热胀冷缩，淘汰。
- **程序生成/自动验收**：从目标长度反推温度区间；约束求解检查交集、可控范围、收敛时间和输入容错。
- **两小时范围**：3 根矩形、线性伸缩、热/冷圆形影响区、目标区与区间求解。
- **同质化/IP 风险**：中低；具体题型较少，但要避开现成热胀冷缩教学游戏的关卡与图示表达。
- **为什么可能已经太晚**：概念比拖拽/点击多一层物理知识，可能排斥低认知负担受众；市场需求仍只是创意推断。

### C11 重心摘取

- **来源类型**：市场事实衍生；来自物理预测/满足崩落的需求母题。
- **一句话**：从悬挂雕塑上依次摘掉 2–4 个配重，让剩余结构在目标角度内平衡。
- **核心动词**：`DETACH`，摘取。
- **30–90 秒循环**：看悬挂结构 → 点一个配重 → 结构摆动稳定 → 继续或失败 → 达到目标；35–65 秒。
- **自然内容钩子**：最后摘掉看似关键的大块，结构反而回正；失败有明显倾覆。
- **两类自愿奖励位**：① 显示当前质心投影带；② 恢复刚摘掉的一块，免费整局重开。
- **会话与广告容量（设计假设）**：7–10 局、5–7 分钟；奖励位 0–2；插屏 0–1 次，仅第 5 局后；日会话 1–2。
- **广告健康检查**：每次点击后节奏连续，广告会放大短局问题；如果无法把单局自然扩到 30 秒以上且仍有决策，IAA 深度失败。
- **程序生成/自动验收**：从稳定末态反加配重；组合枚举删除顺序，检查至少一条宽容序列、摆动稳定、非显然贪心。
- **两小时范围**：刚体横杆、点质量、简谐摆近似、组合求解。
- **同质化/IP 风险**：高；容易靠近螺丝、拆除、Tap Away 类素材，即使质心规则不同也有同质化观感。
- **为什么可能已经太晚**：拆除点击心智与素材供给已经拥挤，局长又浅，无法同时满足低买量与低频 IAA；不进前三。

### C12 一镜多照

- **来源类型**：创意推断；光路/视角是长期谜题母题，但没有近期移动自然需求或 IAA 适配证明。
- **一句话**：转动场中央唯一一面小镜子，让一束光经边界反射后按顺序点亮 3–5 个节点。
- **核心动词**：`ROTATE`，旋转镜面；不使用箭头、管线或逐块拼接。
- **30–90 秒循环**：看光源/节点 → 单指转镜 → 即时光路预览 → 松手发射 → 全亮或显示首次漏点 → 再调；40–75 秒。
- **自然内容钩子**：黑暗场景里一次小角度转动突然拉出完整折线光路，节点依次点亮；“差一度漏最后一点”的结果也清楚。
- **两类自愿奖励位**：① 连续两次漏点后显示可行角度的粗扇区；② 失败详情中显示首次反射后的幽灵段，免费继续试角与重开都保留。
- **会话与广告容量（设计假设）**：6–9 局、6–9 分钟；奖励位 0–2；插屏 1 次，仅第 4 局后且距全屏广告至少 180 秒；日会话 1–2。
- **广告健康检查**：无广告可无限试角和切基础种子；两个奖励只减少盲扫。若连续预览让玩家一转就暴力扫出答案，或关卡需把角度窗压成像素级才产生提示价值，淘汰。
- **程序生成/自动验收**：先选解角并沿解析反射路径放节点，再加入不被该路径命中的诱饵；角度区间扫描验证顺序可达、有效角窗宽度、随机角命中率与确定性。
- **两小时范围**：矩形边界、单光源、一个可旋转镜面、3 个圆节点、解析 raycast、角度扫描与 seed HUD。
- **同质化/IP 风险**：高；激光、镜面与反射谜题已有大量作品，不能复用现成房间、节点、光色、角度或 UI。
- **为什么可能已经太晚**：母题成熟且连续试角天然压低奖励价值；裸几何若没有新鲜感，会成为旧激光谜题的减配版。

### C13 折线导流

- **来源类型**：市场事实衍生；来自画线物理簇，但该簇的近期评论明确暴露超短局和强插广告问题。
- **一句话**：只画一条短折线，放出一股颗粒，让足够多颗粒流进目标容器。
- **核心动词**：`DRAW BARRIER`，画屏障；不分颜色、不做 Sort。
- **30–90 秒循环**：看源/容器/障碍 → 画一条限长折线 → 放流 → 达标或观察泄漏 → 重画；40–75 秒。
- **自然内容钩子**：颗粒绕过看似不可能的缺口形成瀑布，失败时从一个小缝全部漏走。
- **两类自愿奖励位**：① 显示粗粒度流场/危险泄漏区；② 失败后保留轨迹热图并恢复画线前状态，免费重开。
- **会话与广告容量（设计假设）**：6–8 局、6–9 分钟；奖励位 0–2；插屏 1 次，第 4 局后；日会话 1–2。
- **广告健康检查**：不得随机改变颗粒导致人为失败；流动观看本来较长，任何全屏广告都只能在结算后。若帮助成为必需或低端机仿真失真，淘汰。
- **程序生成/自动验收**：从已知屏障正向仿真并扰动；离散流/粒子批量模拟，验证达标率、线长容差、随机线命中率、跨帧率一致。
- **两小时范围**：100–200 粒简化粒子、一条折线、容器计数、固定步仿真、候选线采样。
- **同质化/IP 风险**：高；画线救援、导流和沙粒广告已经非常拥挤，需避免现成容器、障碍和救援叙事。
- **为什么可能已经太晚**：该子类强依赖广告素材与物理奇观，个人自然获量不明；广告不伤体验也低于前三门槛。

### C14 异常一瞬

- **来源类型**：市场事实衍生，但事实主要是**供给过密警告**：当前 Steam 专门策展列表显示数百个 Exit 8-like/异常检测条目，近期仍密集新增。
- **一句话**：在 8–15 秒的重复场景中判断是否发生一处几何异常。
- **核心动词**：`SPOT`，观察判断。
- **30–90 秒循环**：看基准 → 场景闪回/变体 → 左右选择 → 连续 5–7 轮结算；45–80 秒。
- **自然内容钩子**：观众可暂停找不同，评论区争论明显。
- **两类自愿奖励位**：① 冻结一次并在大区域内给提示；② 错误后回放基准/异常叠层，免费开始新串仍可。
- **会话与广告容量（设计假设）**：4–6 串、6–10 分钟；奖励位 0–2；插屏 1 次、最多 2 次，只在完整串结束；日会话 1–2。
- **广告健康检查**：帮助有价值，但主要成本是持续生产不含歧义的场景；若程序异常显得廉价或模糊，会诱发看提示而非乐趣，属于坏内容，不是广告机会。
- **程序生成/自动验收**：参数化场景变体；像素差阈值、显著性/遮挡测试、双盲规则检查、确定性回放。自动化仍无法判断人类是否注意到或觉得公平。
- **两小时范围**：一个几何房间、10 种参数异常、基准/变体切换和差分可视化。
- **同质化/IP 风险**：极高；Exit 8-like 的循环场景、异常类型和二选一表达都有明确既有作品群，不应复制。
- **为什么可能已经太晚**：供给已极度拥挤，PC 成功常依赖氛围、剧情和手工异常，与本项目硬约束冲突；内容供给和 IAA 均不够。

### C15 整盒复位

- **来源类型**：市场事实衍生；近期至少三家独立发行方仍更新“tidy/satis/organize”产品，说明需求母题存在，也显示命名、表现和微玩法高度同质化。
- **一句话**：用一根手指把一盒散乱物件恢复到轮廓槽位，并触发整齐前后对比。
- **核心动词**：`TIDY`，整理复位；不按颜色/类别做 Sort。
- **30–90 秒循环**：看散乱盒 → 拖物件到形状槽 → 对齐反馈 → 全盒完成；45–90 秒。
- **自然内容钩子**：混乱到严丝合缝的强前后对比，视觉传播很强。
- **两类自愿奖励位**：① 显示一个物件的槽位轮廓；② 纠正一次已经放错但尚未锁定的摆放，免费拖回/重开仍可。
- **会话与广告容量（设计假设）**：5–8 盒、8–12 分钟；奖励位 0–2；插屏 1–2 次，第 4/8 盒后；日会话 1–2。
- **广告健康检查**：结构上有会话深度，但舒缓体验对全屏广告非常敏感；如果没有大量内容只能重复同一盒，不能用广告频次补库存。
- **程序生成/自动验收**：可用多边形装箱生成并求解碰撞，但“有趣、可辨识、治愈”的物件与摆放大多仍需美术/人工判断。
- **两小时范围**：6 个多边形、轮廓槽、拖放吸附、碰撞和装箱校验。
- **同质化/IP 风险**：极高；移动端和 Steam 的 tidy/satis/organize 命名、物件和 UI 都高度相似，任何复用都不可接受。
- **为什么可能已经太晚**：用户已期待高质感 ASMR、美术和每周内容，违反个人低内容成本优势，广告也易破坏放松。

### C16 一键滚球

- **来源类型**：市场事实衍生；Going Balls、Color Switch、Stack Ball、Tap Tap Dash 等独立发行方产品在观察窗仍更新且规模巨大，但这是成熟存量/发行能力信号，无法证明新作可自然获量。
- **一句话**：单指点击改变球的轨道状态，在短障碍链中坚持到终点。
- **核心动词**：`TAP`，点击切换。
- **30–90 秒循环**：连续点击/松手躲障碍 → 失败立即重来 → 30–60 秒结算。
- **自然内容钩子**：极限擦边和高节奏连过，容易做可玩广告式画面。
- **两类自愿奖励位**：① 失败点前给一次慢速预演；② 中段真实失败后续跑一次，免费从头重试。
- **会话与广告容量（设计假设）**：8–15 局、4–7 分钟；奖励位 0–2；自然插屏 0–1 次，仅第 6 局后；日会话 1–3。
- **广告健康检查**：这种短失败循环几乎只有“续关”强位；插屏会直接打断熟练节奏。近期商店评论已反复抱怨每几局甚至每局广告，因此两项 IAA 门槛失败。
- **程序生成/自动验收**：从机器人可行点击序列生成障碍；固定步回放、反应窗口、随机点击成功率和难度曲线。
- **两小时范围**：球、两态轨道、20 个障碍、确定性序列与机器人回放。
- **同质化/IP 风险**：极高；单触滚球、换轨和冲刺已有海量产品，不能复用轨道、障碍、角色或数值。
- **为什么可能已经太晚**：市场巨头存量、同类素材和买量能力远超个人；没有新的核心动词，也容易沦为高频强插模型。

## 4. 跨候选淘汰观察

- **物理增长不是空白市场**：分析资料显示物理谜题收入增速明显高于下载增速，更像成熟产品加深变现/生命周期，而不是新增受众爆发。C07/C09/C13 不能因为“物理好拍”就默认有自然需求。
- **舒适整理有需求，也有内容税**：三家以上移动发行方近期仍在更新，Steam 评价从极好到混合并存。强前后对比值得抽象，但手工物件、ASMR 和持续更新不适合低内容成本矩阵，故 C15 被淘汰，C02 只保留程序图案版本。
- **单触大盘不等于个人机会**：巨量历史安装与近期更新说明玩法可长寿，也说明入口已成熟；近期评论对“每几关广告”很敏感。C16 作为反例而非候选方向。
- **异常观察已经拥挤**：短视频钩子强，但 352 条策展结果与手工异常成本构成双重否决，C14 不值得再追。
- **40+ 与低端 Android**：中国平台大会转述支持 40+ 用户规模值得关注，海外问卷也显示年长玩家使用手机玩免费游戏；但这不是上述任一核心动词的适配证明。当前只把它转成大触区、低文字、高对比、2 GB RAM 档和确定性低粒子预算，不将“银发”写进题材或收益预期。
