## 验收场景

玩家用左侧摇杆移动，靠近顾客/工位用右侧按钮操作；A 后台吹发时去处理 B，A 到点后返回收尾，等待中的 C 始终显示需求与耐心。洗＋剪完成直接结束。一次轻微松手失误可继续完成，不因一时操作失误立刻终止整单。每局有明确目标与结果，能重试或继续营业；已结束营业与购买设备在刷新后保留。首日目标暂定 3 单，第二、三日为 4、5 单，第 3 天以后暂维持 5 单；排队上限和后台交错从第一天出现。目标与满意度惩罚仍需真人验证，不根据自动脚本成绩推断真人通关率。

## 工作边界

- 主场景仅由主任务修改，Luna workers 不触碰 `SalonDemo.cs`、正式场景或其他 worker 的文件。
- 现有工作区有大量未提交内容，所有任务均保留这些内容，不回滚或覆盖无关变更。
- 首先落实当前洗剪吹循环，保持已批准角色、美术方向和布局；不扩展多人、新服务或新货币。
- 广告平台暂缓确定，正式 Demo 不显示虚假的可看广告按钮，也不通过模拟回调发放广告奖励。
- 自动测试通过不等于已完成真机和真人体验验收；最终说明需明确实际验证范围。
