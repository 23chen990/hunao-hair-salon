# 首日节奏与成长调度交付记录

日期：2026-10-01（用户客户端日期）。

## 本轮解决什么

按产品负责人同轮补充，目标是：**始终有可理解的事做，但能处理得过来**。循环为先学会服务 → 小批处理 → 收银 → 低压补货/建设或及时接下一位 → 用收入扩展已理解的能力。保留批准的角色、房间布局、美术方向、服务操作和既有七项建设路线。

本轮由主线程独占主场景集成，三位 Luna worker 分别负责竞品研究、旧回归测试适配、真实 Chromium 触控验收。中断续做时另由一位 Luna 只读核对验收脚本与实现描述，主线程完成最终重跑、工具修正和交付。

## 已实现的规则

| 环节 | 新规则 | 防止的问题 |
| --- | --- | --- |
| 新手开局 | 前两位顾客逐位完成并收钱；首日最多两位有效工作顾客，但不强行填满 | 一开始就被多个订单打断 |
| 新业务 | 吹风/洗头各自第一位一对一教学；仍使用原有剪吹、洗剪订单，不新增单独洗/吹玩法 | 买到设备后立刻堆陌生流程 |
| 批次 | 基础批次最多两位；全部付款或离店后，有可负担施工/可补库存才给最多 8 秒经营窗口；没事做只约 2 秒过渡，管理任务做完也提前结束窗口 | 用强制空白伪造“喘息”，或把收银路程算作休息 |
| 工作负荷 | 服务完成动画 `Finished`、走向收银、待结账都算工作；只有 `Leaving/Exited` 不算 | 服务完成但尚未收钱时错误补客 |
| 首日波形 | 约 58–72 秒、130–142 秒为低压消化段，有顾客时不再叠额外工作；空店且无经营任务仍可接一位，不机械停客 | 从开门到关门持续高压，或在空店强制等待 |
| 空店衔接 | 没有有效顾客和经营任务、短过渡结束后，不再等待上一笔随机上客冷却 | 玩家没有事做却仍被刷新计时器拦住 |
| 收尾 | 正常营业最多 180 秒，约 148 秒后不接新客；所有顾客离店、款项结清后自然结算，不看空店倒计时；尚有服务则保留最多 15 秒收尾 | 快关店时塞长单，或无事可做还强等到时间归零 |
| 洗剪分流 | 根据已建好工位、当前需求、洗发水及已预留库存选单；洗头需求满额/缺货不再加洗头单，有剪发能力则选择可做的短单 | 全队等洗头、理发椅空着 |
| 订单难度 | 新手短单占主要份额；已付款的吹发、洗头各至少三单后才会出现三步组合单 | 只因时间到了就自动变成复杂订单 |
| 成长客流 | 实际付款经验与工位能力共同决定软上限：基础两位，熟悉流程并有第二椅后最多三位；更成熟且有后期能力后最多四位 | 天数、余额或座位数直接等于必须接待人数 |
| 扩建适应 | 若扩建会提高软上限，先维持购买前上限，再完成并付款两单后放开；新旧购买路径都覆盖 | 刚买设备就被新客流抵消收益 |
| 存档 | 已付款顾客数、吹发/洗头经验及扩建缓冲一起保存、克隆和校验；旧存档保留钱与设备，缺失经验时温和复习 | 刷新后突然变难或丢成长记录 |

首日等待耐心约 62.5 秒，后续约 55.6 秒（基础等待计时；服务延误规则另计）。这不是让顾客无限等待；主要减压来自少接无法处理的订单。

## 金币与成长

保留批准路线及价格：吹风机 600 → 洗头台 1,200 → 第二理发椅 2,000 → 等候座椅 2,400 → 吹风支架 3,000 → 第二洗发区 3,600 → 加座长凳 4,200。仍然一次显示一个施工点，钱够可提前买，没有新增按天硬锁。

- 前两次剪发和收银帮助理解基础闭环，再用收入买吹风机。吹风增加收入和流程，不是免费减少椅子占用。
- 洗头先在低压教学中掌握泡沫、冲洗、库存，再把洗头单与剪发单交错。
- 第二椅、吹风支架、第二洗头区应解决实际容量或操作瓶颈，购买后先享受改善。
- 等候座椅缓解等待耐心压力，不能替代服务产能；最后长凳才增加两位等候容量。
- 后期第二洗头区/长凳的性价比与顺序仍需更长线真人试玩；本轮不假装已定死最优价格，不擅自增加员工、宣传、货币或机关。

竞品事实与本作推导分开记录在 `RESEARCH.md`。没有把竞品介绍页当作精确上客秒数、平均购买时间或后台调度算法的证据。

## 体验方法与边界

1. 启动 `python3 tools/serve-salon.py --bind 127.0.0.1 --port 8877`。本轮已启动该本地服务；正式 Demo 为 `/WebGLDemo/`，实验室为 `/WebGLAssetLab/`。原有 8765 服务没有被关闭或替换。
2. 用新存档进入第一天，先完成接待、剪发、收银；钱够施工或需要补货时看看是否有低压时间操作；没事可做时看看下一位是否及时出现。不要删除原进度来配合验收，可用无痕窗口另开新档。
3. 买吹风机后观察一对一教学；买洗头台后观察洗剪分流，而不是持续洗头排队。
4. 扩建第二椅后留意先有余裕，再在两单练习后逐步放开客流；刷新应保留收入、设备和学习记录。

真实触控自动化能检查可达性、调度、收入、存档和明显队列问题，不等同于不同熟练度真人的主观体验。未改变批准的视觉方向；截图只报告当前画面与安全区，不宣称与未指定基准逐像素一致。
