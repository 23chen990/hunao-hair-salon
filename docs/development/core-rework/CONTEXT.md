## 产品负责人反馈（原话要点）

1. 第一天很空闲、没有忙乱感；操作顾客时进度条显示不对；引导顾客到剪发工位时顾客在工位边乱走；顾客离开时在店内突然消失，而不是走到门口离开。
2. 新顾客刷新太慢。
3. 成长不合理：开局应只有理发工位，接待一两个顾客后再解锁新工位。
4. 保留《猴子超市》顾客到收银台结账的玩法。
5. 看不懂怎么洗头，补货引导不够。
6. 顾客太有耐心。
7. 失败（例如剪过头）顾客不生气、没反应，只是不给钱，没有搞笑感。

## 已确认的新规则

- 结账：完成服务的顾客走到收银台排队；玩家站在收银台前自动逐个结账，金币飞入余额；等太久没人收钱则不付钱离开、扣口碑。
- 带客：接待后顾客跟在玩家身后；玩家在空闲工位按一下，顾客直接入座。
- 洗头：按住打泡沫 → 可离开 → 头顶圆环约 8 秒倒计时 → 回来冲洗；放太久出搞笑失败。与吹风同一套“开始—走开—回来收尾”规则。
- 解锁：花赚来的钱、一个接一个解锁，不按天开放。开局 1 把理发椅 + 收银台，顾客只点剪发，开局送 100 金币。顺序与参考价：吹风机 600 → 洗头台 1,200（附送一批洗发水，剩 2 瓶时旁边免费出现补货架并教补货）→ 第二理发椅 2,000 → 等候座椅 2,400 → 吹风支架 3,000 → 第二洗发区 3,600 → 加座长凳 4,200。同屏只显示 1 个施工点，买完立即出现下一个；顾客只点已建好的服务；新工位建好后立刻来一位点该服务的顾客。
- 店门：左墙前段开门，顾客从店外经门进入、经门离开，走到店外才消失。房间内家具相对布局不变。

## 交付批次

1. 修 Bug：进度条、入座乱走、离店消失与店门。
2. 节奏与情绪：刷新更快、耐心更短、三段等待情绪、失败搞笑反应。
3. 成长与流程：解锁链、收银台结账、跟随带客、洗头新流程、补货引导。
