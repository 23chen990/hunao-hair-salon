# 镜头实际显示范围修复

本轮先重现 960×540 后墙角人物被任务条遮挡、双人底部按钮遮挡等候区。初次修复为顶部提示和底部按钮预留画面空间，空物体投影测试通过。但真实 Chromium 844×390 截图 `FirstSessionVisual/second-pass/844x390-single-business-p1-moved.png` 仍显示头发被盖住，初版不能按“修好”交付。

进一步确认：理发师使用朝向镜头的完整角色图片，不能用沿世界竖直方向估算的两单位高度代表实际头顶。新增测试实例化正式 Hairdresser 角色，按真实图片四角检验后墙取景。`SecondPassBillboardRed.xml` 三项均失败：头顶投影约0.781，越过任务条保留区0.701。

正式修复读取当前角色图片的显示范围，为头发、身体和脚底保留空间；阴影和手持用品不作为人物高度。双人靠近时同时保护两人，分开太远则保留整体取景，避免为了避开界面将人物缩得过小。

补充后全量 `SecondPassRenderedFinalEditMode.xml` 为734/734通过，0失败。最终构建与画面复核结果在同目录 REPORT.md 记录。此前初版截图保留为发现遗漏的证据，不当成最终通过图。
