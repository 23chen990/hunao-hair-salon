# 第二轮试玩改进

2026-09-28。本轮由主任务负责实际画面复核和最终集成，Luna 分别负责控件、满意度边界检查、两日触控对比。最终包浏览器验证进行中。

## 离产品目标还有多远

目前已经具备“接待 → 洗剪吹 → 收入 → 扩建 → 继续营业”的可玩骨架，但还不能算体验成熟。与“手机横屏、容易上手、忙得有意思、跑腿与扩建形成持续动力”的目标相比，差距主要在三处：

1. **操作信息还需打磨**：服务多起来时，玩家仍需要同时读顶部任务、顾客气泡、队列和按钮。修好遮挡与明确下一步是必要条件，还不足以证明陌生玩家能自然理解。
2. **忙碌节奏和成长感还需验证**：连续营业能够达标，满意度却仍偏低。需要分清真实等待、事故、返工和到点关门的后果，再看哪些压力让玩家觉得合理。现有扩建已能增加实际工位，但“有收益”还不能代替“玩家明显感觉变好经营”。
3. **整店视觉尚未完成**：当前主控角色、洗发台与占位顾客、周边家具的完成度不一致，仍明显低于已批准效果图。此次保持美术方向与布局，没有声称整店已达标。

## 本轮完成的调整

- **打烊边界更清楚**：仍有耐心、尚未接待且没有真实错误的顾客正常离开，不再在最后结算时被全部当成服务失败。做坏的订单、等太久离开的顾客、接待后没做完的服务仍保留后果。
- **日结解释更完整**：同一张结果页增加“未完成服务”和“打烊未接待”，与“流失顾客”分开展示，收入和施工进度继续保留。
- **补货下一步更明确**：空手时提示去右侧取货，拿到用品后提示送回洗发区，用品耗尽时不再指向空货源。
- **人物可见范围更准确**：镜头为顶部提示和底部操作预留空间，并按角色实际图片大小保护头发和脚底。初次修复在实机截图中仍挡住头发，已保留失败图并继续修正。
- **双人按钮占用更少**：保持左右分区与原操作位置，降低按钮和底部提示的高度；640×360 下操作区域仍至少为 44 像素高。

营业时长、每日目标、奖励、耐心数值、角色、家具布局与美术方向均沿用现有设置。

## 限制

- Chromium 真实输入与手机横屏尺寸模拟已用于复现；未完成实体手机上的触感、发热、性能验收。
- 自动触控会按固定路线行动，并单独验证提前松手、暂停、剪过头等情况；它能验证流程，不能证明乐趣、留存或真人首局体验。
- 双人分开过远时仍优先保持两人同时入镜，不能承诺整店所有位置都避开界面。
- 本轮没有扩展玩法或新系统；满意度与长期经营节奏仍是后续体验打磨重点。
