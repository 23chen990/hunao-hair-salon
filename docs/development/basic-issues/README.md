## 2026-09-30 产品负责人决定与实施进度

决定：地图走 B（在现有店外逐块长出新区域）；第一块是第二洗发区；烫发位和第二洗发位并入扩建路线；客流改成平稳—高峰交替；声望让玩家看得见，并加防连败保护。

- **第二洗发区（已实现）**：右墙外新建一间洗发房。按[店铺解锁路线](unlock-route.md)第 3 天开门出现施工圈（在右墙内侧），2,000 金币，站在圈里每秒投 250 金币、约 8 秒攒满；攒满后旧右墙打通、4 号洗发位搬进新房间、两位顾客可同时洗发。顾客经门洞进出，不穿墙；可走面积和镜头范围一起扩大；存档、刷新、再试一次都能保留。
  - 限制：没装 Blender，所以新房间墙地面按原房间的材质和尺寸用代码拼出来；原右墙前段在打通后降成矮墙（和左侧矮墙一致），避免高墙挡住新房间。
- **客流节奏（已实现，待实机手感校准）**：每天分成平稳 → 上客 → 平稳 → 高峰 → 收尾五段，顶部目标栏显示当前段；快打烊时停止进新客。模型模拟里“有人排队的时间”从约 96% 降到约 64%，最长空档约 29 秒，1 星口碑下三天目标仍能完成。
- **口碑（已实现）**：开店卡显示“口碑 X 星 · 客流 ±N%”，结算显示“口碑 A 星 → B 星 · 明日客流 ±N%”。每星影响客流 ±12.5%（范围 −20% 到 +25%）。正常做完一单 +0.03、满意 +0.05，走单 −0.06、打烊时做到一半 −0.02、不满意 −0.06/−0.10；每天最多涨 0.1、跌 0.2；打烊时没来得及接待不扣分；“再试一次”会恢复开店时的口碑。
  - 实测修正：第一次两日触控里，一、二步订单的顾客满意度最高只有 76/82，永远到不了“满意”线 85，而正常完成原来记 0 分，所以达标的日子口碑也只会往下掉（3.00→2.86→2.72）。现在正常完成也加分，达标且只走一单的日子大致持平。
  - 第二次修正：复测两天都达标，口碑仍是 3.00→2.98→2.88。原因是打烊时还在服务中的顾客每人扣 0.08，差不多抵掉三单正常完成；第 2 天有两位正做到一半，就扣了 0.16。《胡闹厨房》到点时锅里没做完的菜不扣分，所以改为每人只扣 0.02。按同样的两天重算，结果是 +0.04 和 +0.02。
- **烫发位（未开始）**：仍隐藏，排在第二洗发区之后。

## 待处理（按优先级）

以下为 2026-09-30 决定前的原始诊断，当前进度以上一节为准。

### 1. 地图定死、扩建没有空间成长（已定方向 B，第一块新区域已完成）

- 整间店在一屏内，四面是墙。开局可走面积约 188，买了理发扩建后约 258，只是同一间屋子右半边打开，增长 1.37 倍。
- 没有新房间、等待区、后场通道或门口外摆；决策文档 0003 定的《Monkey Mart》式“店面随扩建长大”没有做。
- 从门口到收银，各关键点之间直线只要 1–2 秒。
- 三个方向：
  - A 只调镜头：成本小，但不解决长不大。
  - B 在现有店外按 0003 逐块长出新区域：成本中到大，最贴近已定方向。
  - C 开局更小、后期多房间：成本大，要重做首局。

### 2. 客流一直满载，没有“平稳—高峰”的节奏（已实现，待实机手感校准）

- 两日实测里，96% 的时间都有人在排队，92% 的时间有人没被接待；第 1 天结算显示流失 1 人、未完成 2 人、打烊时未接待 2 人。
- 决策文档 0003 定的是“平稳跑腿和高峰手忙脚乱交替出现”，现在是从头忙到尾，完成目标更像“凑够单数”，不是掌控店面。
- 最大的单点瓶颈是洗发：5 种订单里有 3 种要洗发，但只有 1 张洗发台可用。本轮修的“冲洗后卡死”就发生在这里。

### 3. 做了一半的工位（4 号洗发位已并入第二洗发区；烫发位未开始）

- 模型里有 5 个工位，手机开局只能用 2 个，全部扩建后也只有 3 个。
- 烫发区（3 号）和第二张洗发位（4 号）在手机版里被整体隐藏，玩家看不到，但也没有任何解锁路径，等于做了一半的内容。

### 4. 满意度几乎没有长期后果（口碑已可见并加强）

- 声望其实每天都在结算和存档，并已经让客流按 ±10% 变化。但玩家在哪里都看不到它，幅度也小到感觉不出来。服务好坏实际上只影响当天分数，玩家没理由追求服务质量，只需凑够目标单数。
- `ReputationSystemEnabled` 开关只用于标记“声望不显示”，不控制结算。
- 这也是后期网红、宣传等机关的前提。

### 5. 扩建形态不统一，成长路线很短（已统一为场景投币点，路线延长到第 5 天）

- 目前有三种形态：理发扩建是场景内施工圈，补货架也是施工圈，自动吹风支架却是闭店弹出面板。
- 一共只有三项扩建，熟练玩家大约第 3 天就买完，之后赚的钱没有去处。

### 6. 较小的问题（通常不需要批准）

- 泡沫、吹发到了该回来收尾的时候，只靠进度条变色提示，没有声音或闪烁。压力大时，玩家要同时看顾客卡、顶部任务、气泡和按钮。
- 刷新或中途退出后，只恢复余额、天数和扩建，不恢复正在进行的服务；现在也没有告诉玩家会回到开店前。
- 至今只在电脑浏览器里模拟过 844×390 触控，没有实体手机和陌生玩家的试玩证据。

## 依赖关系

- 地图方向（第 1 项）决定第 2、3、5 项怎么修。例如第二洗发区如果放进新区域，就同时解决洗发瓶颈和“4 号洗发位用不了”。
- 客流节奏（第 2 项）应在地图和工位定下后，用真实触控重新校准。
- 声望（第 4 项）可以和地图并行，改动不碰布局。
