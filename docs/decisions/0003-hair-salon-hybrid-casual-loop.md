# 《胡闹理发店》混合休闲玩法定位与空间扩建机制

> 产品负责人确认日期：2026-09-23
>
> 本文记录产品玩法方向，不代表下方所有系统已经接入当前正式 Demo。

## 1. 品类定位

《胡闹理发店》是一款结合《胡闹厨房》短时高压服务链和《Monkey Mart》跑腿补货成长循环的**混合休闲（Hybrid Casual）**手机游戏。

更具体的形态是：

- 事件驱动型街机经营；
- 轻派对属性的动作经营；
- 带轻度自动化成长的街机放置；
- 单人虚拟摇杆跑腿与多任务统筹。

它不是传统的菜单式模拟经营。玩家直接操控理发师在店内移动、补给、安排顾客和处理服务，平稳的跑腿积累与高峰期的手忙脚乱交替出现。

## 2. 核心循环

```text
[补给与跑腿]
      ↓
[解锁洗剪吹工序]
      ↓
[顾客增多、订单变复杂]
      ↓
[高峰客流或突发状况]
      ↓
[跑动救场]
      ↓
[获得营业收益]
      ↓
[扩建店面、增加工位与自动化设备]
      ↓
[进入下一轮更高压力的营业]
```

## 3. 三个阶段

### 3.1 前期：店内补给与跑腿布局

- 用虚拟摇杆移动理发师，在仓储区、等待区和服务区之间往返。
- 搬运毛巾、洗发用品、剪发工具和吹发用品，及时补充到工位或工具架。
- 背包容量有限，物资堆叠、卸货和回到工位都提供即时声画反馈。
- 通过扩建补给架、洗发区、理发区和等待区，让路线逐渐变得高效。

### 3.2 中期：洗剪吹装配链与动线瓶颈

顾客需求从单一步骤变为组合订单：

```text
洗发 → 拆毛巾 → 剪发 → 吹发
```

玩家需要在顾客、工位、工具和补给之间调度。吹发可以后台推进，玩家可以先去接待或服务另一位顾客；工位占用、排队和交叉路线会形成动线瓶颈。

### 3.3 后期：高峰客流与突发状况

- 高峰期出现多位加急顾客、连续预约或复杂组合订单。
- 顾客耐心与营业倒计时制造优先级冲突。
- 设计方向可以包含设备故障、地面湿滑、通道杂物和特殊顾客等事件，让玩家临时改变路线和服务顺序。
- 成功处理高峰后，玩家获得更高的营业收益或扩建进度。

## 4. 核心机制：空间触发式自动扣费扩建

### 4.1 机制定义

空间触发式自动扣费扩建（**Proximity Trigger Pad / Diegetic Purchase Pad**）是《Monkey Mart》式街机放置感的关键来源。

店内的新设施不通过“打开背包 → 进入建造菜单 → 选择设施 → 确认放置”完成，而是以场景中的施工点出现：

```text
[发现半透明施工轮廓]
      ↓
[走入并停留]
      ↓
[营业余额自动扣费]
      ↓
[设施现场组装]
      ↓
[开放新的服务能力或路线]
```

### 4.2 零 UI 的空间交互

施工点在世界中直接显示设施轮廓、价格和解锁预览。玩家只需要把理发师跑到光圈里，不需要额外打开菜单或确认放置。

可作为施工点的设施包括：

- 第二张洗发床；
- 新的理发椅；
- 毛巾或洗发用品补给架；
- 自动吹发设备；
- 等待区扩建；
- 缩短路线的后场通道。

### 4.3 站位自动倾泻扣费

玩家进入施工圈后，余额以连续的声画反馈投入设施：

- 资金图标从角色或余额位置飞向施工圈；
- 金额数字持续倒数；
- 播放吸附声、连续提示音和粒子效果；
- 进度归零后，家具从蓝图中弹出并完成组装。

这里使用的是现有钱包中的营业余额，只表现为扩建扣费的视觉倾泻；不新增独立货币，也不恢复订单金币堆或额外拾取循环。

扩建完成后，附近下一个施工点亮起，形成不依赖任务列表的视觉引导链。

### 4.4 扩建必须改变玩法

每个施工点都应该改变路线、容量或服务效率：

- 新洗发床提高同时服务顾客的能力；
- 新理发椅减少剪发排队；
- 补给架缩短往返仓储区的距离；
- 自动吹发设备让一项服务在后台推进；
- 新通道减少拥堵；
- 等待区扩建提高可接待人数。

## 5. 当前 Demo 的边界

- 当前正式 Demo 已有单人跑位、顾客排队、洗剪吹组合服务、后台吹发和营业压力。
- 当前正式 Demo 的订单收入在完成订单后立即结算到余额，不生成或要求玩家拾取金币堆。
- 通用区域扩建、场景购买点和连续施工点目前尚未实现；本文记录的是已确认的产品方向和目标交互。
- 真正落地前，需要同步设计购买模型、存档字段、场景/Manifest、占地与碰撞、导航、扩建后的工位能力，以及自动化和 Chromium 回归。设备故障、湿滑地面和特殊顾客等突发状况目前只记录为后续设计方向，不代表当前 Demo 已实现。
