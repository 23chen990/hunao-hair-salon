# 《胡闹理发店》空间触发式投币解锁接入

> 接入日期：2026-09-24

## 目标

在正式手机 Demo 中加入一个可玩施工点：玩家走进洗发补给架旁的施工光圈，沿用现有营业余额自动投入金币，完成后在洗发区附近生成第二个补给架。

## 交互规则

- 施工点显示固定价格和已投入进度，不打开建造菜单。
- 当前施工点 ID 为 `expansion-pad-wash-rack`，总价 180，站位时按 60 金币/秒投入。
- 玩家停留时按时间片扣款，扣款只能通过现有 `SalonPaymentModel.TrySpend`。
- 离开光圈保留已投入金额，重新进入继续施工。
- 余额不足时暂停，不产生负余额。
- 达到价格后只触发一次解锁，生成新货架并缩短洗发补货路线。
- 施工状态写入现有进度数据中的可选布尔字段；不新增货币，也不改变订单收入规则。

## 本轮范围

只做一个洗发补给架施工点。多级施工链、飞行金币粒子、设备升级和其他区域扩建留到后续阶段；本轮先保证扣费、状态和路线变化可玩且可测试。
