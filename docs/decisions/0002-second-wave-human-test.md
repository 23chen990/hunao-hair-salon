# 决策 0002：第二轮唯一陌生真人测试对象

> 日期：2026-08-10  
> 状态：只锁定人测顺序，不是产品 KEEP，也不授权正式开发、发布或投放

## 结论

三款 120 分钟抛弃式灰盒的机器门槛均已由主任务独立复验全绿。唯一推荐进入陌生真人静默测试的是 **P1《叠孔通路》**。

P2《滚筒成章》和 P3《呼吸桥》保留为“技术通过、产品未决”，本轮不继续加 UI、美术、Meta、广告 SDK 或正式工程。这个排序只是在三个未被证明好玩的候选里，选择最值得花一次真人样本的对象。

## 为什么唯一先测《叠孔通路》

1. **更符合个人开发者的可控成本。** 规则是离散平移、放珠和明确阻挡层；内容可反向生成并由 BFS 验收，不依赖软体物理调手感，也不需要大量手绘图案。
2. **失败反馈最容易成为广告价值，而不必破坏基础循环。** “下一张该动的层”和“首次阻挡慢放”是两个不同且真实的可选帮助；免费重试、完成和下一基础 seed 在广告关闭时仍然完整。
3. **IAA 会话结构在三款中最宽。** 当前代理为 8–12 分钟、两个自然结算资格点；仍须真人证明玩家真的会玩到这些断点。
4. **传播画面可在灰盒直接判断。** 最后一次对齐后珠子贯穿全部薄片，成功/阻挡的因果比滚筒的起始角—方向—距离三变量更单纯，也比软体膜更不依赖设备帧率与手感。
5. **机器随机成功极低但答案不要求像素级操作。** 这降低“乱拖也过”的风险；反面风险是可能太难或层关系不可读，因此必须把 10 秒可懂作为人测第一项，而不能据机器数字直接立项。

## 为什么另外两款暂不先测

- **《滚筒成章》**：机器正确性很强，但新玩家要同时理解起始面、方向和拖动距离，且满足类画面对图案和材质的预期较高。它更可能在灰盒里被误解为随机落印。
- **《呼吸桥》**：单指操作最简单，但 23.02% 的随机模型成功率接近可接受区间上半部；真正价值依赖“控制感”与低端机上的物理手感。当前 IAA 代理也以每会话一个插屏资格为主，优先级低于 P1。

## 唯一真人门槛

测试对象只用《叠孔通路》，不并行测试三款。每位参与者不得先看规则或听口头解释；只观察：

1. 30 秒内是否有意做出“移动一层 → 放珠验证”。
2. 失败后是否能根据首次阻挡层调整，而不是继续乱拖。
3. 连续 5 局中是否至少完成 3 局，并主动开始第 5 局。
4. 是否认为两个帮助入口有价值但并非基础通关必需。

在取得陌生真人数据前，不创建正式第二款工程，不生成正式 UI，不接广告，不把任何候选写成 KEEP。当前唯一外部阻塞是：需要一个不使用私人抖音号、可获得陌生玩家反馈的测试渠道。
