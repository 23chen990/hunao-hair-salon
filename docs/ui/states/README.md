## 未来生产资产拆分

真人玩法 KEEP 后，应重新按独立状态生成、清边并人工校正以下资产，而不是从本目录整屏图直接裁切：

- 桌面背景与可平铺纸张纹理。
- 竞技盘胡桃木外框、浅色盘面和独立珊瑚危险边界；外框需要安全区与九宫格方案。
- 中心之家：常态、成功回响、同步缺位提示。
- 普通外逃棋子：本体、深灰向外箭头、向外箭簇；箭头需支持旋转。
- 已折返棋子：本体、青绿描边、向内箭头、向内箭簇；不得只换色。
- 点击原点与单次涟漪环；半径、圆心和透明度由引擎实时控制。
- 越界局部反馈：边界亮光、裂纹/缺口形状和短暂冲击，不改变碰撞轮廓。
- 同步反馈：空插槽、时钟刻度、成功暖金回响。
- 结果文案容器及待点击、扩散、成功、越界、超时的文字层；文字应由引擎排版，不烧进背景位图。

生产拆分后还需检查 390 × 844 与 430 × 932 安全区、九宫格拉伸、色盲可读性、低亮度对比度、棋子旋转后的箭头方向，以及低端机上透明涟漪的填充率和过度绘制。
