# 《相位涟漪》UI 介入计划

> 日期：2026-08-10  
> 状态：核心玩法屏视觉方向探索完成，尚未进入生产资产拆分

## 原则

UI 是玩法表达的一部分，但不能代替玩法。当前技术灰盒已 KEEP，因此现在可以开始画“核心玩法屏”；首页、商城、签到、任务、广告入口和长期 Meta 仍然延期。

视觉稿与未来位图资产使用图像生成制作，不用程序几何占位图冒充最终美术。必须实时响应规则的元素，例如涟漪半径、棋子位置、方向轨迹和同步窗口，仍由引擎根据游戏状态渲染；这属于交互实现，不是手绘美术。

## 介入顺序

### 现在：核心玩法屏

只解决五个问题：

1. 中心一眼被理解为“家/归心目标”。
2. 外圈一眼被理解为危险边界。
3. 外逃与折返不能只靠颜色区分，还要有方向形状。
4. 点击涟漪必须是屏幕第二强视觉层级，不能遮挡棋子。
5. 成功、越界和同步超时三种结果无需长文字解释。

### 外部可读性验证前：五状态稿

- 待点击。
- 涟漪扩散，0/4 已折返。
- 涟漪扩散，1/4 已折返。
- 全部归心成功。
- 越界/同步超时失败。

这五张通过后，才允许更新验证素材。每次只比较一个变量：明暗主题、方向标记或文案，不同时改三项。

### 真人玩法 KEEP 后：生产资产

使用选定视觉方向继续生成并拆分：背景、竞技盘框、中心目标、普通棋子、已折返棋子、危险边界、结果面板和按钮状态。随后接入正式 Cocos Creator 工程并检查安全区、九宫格拉伸、低端机性能和色盲可读性。

### 留存成立后：外围页面

只有 D1/D7 证明确有重复使用，才画主页、关卡选择、每日挑战、提示/去广告和轻收藏。现在不为这些页面花时间。

## A/B 视觉方向

### A：月夜潮庭

文件：`phase-ripple-core-screen-v1.png`

- 优点：中心“莲灯之家”、水面涟漪和危险岸线形成强情绪记忆，短视频画面更有识别度。
- 风险：装饰密度偏高，暗色在低亮度手机上可能损失方向信息，生产资产拆分成本较高。
- 用途：保留为氛围和品牌候选，不直接拍板。

### B：桌面磁力玩具

文件：`phase-ripple-core-screen-v2-tabletop.png`

- 优点：箭头、轨道、中心房屋和珊瑚边界最直观；明亮、高对比、容易拆分成低成本资产；对较广年龄段更友好。
- 风险：情绪记忆弱于 A，需要靠成功动效与触感补足传播力。
- 当前推荐：**B，先验证可读性；A 保留为品牌皮肤候选。**

## 禁止事项

- 不因视觉稿漂亮就宣布玩法成立。
- 不把生成整屏图直接切片当正式资产；生产阶段必须按状态拆分、核对边缘并进行屏幕适配。
- 不复制具体游戏的 UI、角色、icon、装饰纹样或商店截图。
- 不生成虚假按钮、虚假广告素材或游戏内不存在的效果。
- 不在灰盒阶段确定付费入口和诱导广告位置。

生产级竖屏手游核心玩法屏；保留同一真实机制与物体数量；原创“桌面磁力玩具”主题，羊皮纸、浅鼠尾草、深青、珊瑚红、陶瓷棋子与胡桃木边框；通过箭头形状而非只靠颜色区分外逃/折返；精确文字同上；禁止外围系统和虚假功能。

## 下一决策

先把 B 方向扩展成五状态小套图，再做一次静音可读性审查。若方向标记仍不能让人理解“点击位置决定触发顺序”，UI 判 ITERATE；不能通过增加说明文字掩盖核心问题。
