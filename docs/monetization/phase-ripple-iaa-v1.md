# 《相位涟漪》IAA 节点 v1

> 状态：只验证机会是否自然，不接广告 SDK，不伪造收益。

## 当前可验证节点

### 1. 失败后的可选落点提示（优先）

- 玩家失败后可直接重试，不强迫观看。
- 另一个按钮是“看落点提示”，正式版本可承载一次奖励视频。
- 奖励内容是下一次尝试显示安全落点区域，和失败原因直接相关。
- 当前原型只记录 `hint_requested`，用于判断玩家是否真的需要这个奖励。

这是首个应验证的变现机会：如果失败玩家没有主动点提示，不能因为“这里能放广告”就接入。

### 2. 完整三回合关卡后的自然间隔（候选）

- 一个完整关卡由 3 个短回合组成，目标时长约 30–60 秒，而不是每 4 秒结算一次。
- 只有完整关卡结束才存在插屏候选；前两关默认不展示。
- 正式版本仍需设置会话频控，不能每关固定弹出。

### 3. 连胜保护（后置候选）

- 仅当数据证明玩家在意连胜后，失败时才可提供一次奖励视频保护。
- 如果连胜对留存无贡献，则删除该节点，不人为制造损失焦虑。

## 明确不做

- 不在每个短回合后弹插屏。
- 不把“继续游戏”绑定强制广告。
- 不先造金币、宝箱或签到，再用虚假经济制造广告需求。
- 不接广告前先验证 `hint_requested / failure`、完整关卡完成率和主动下一关率。

## 首轮判断指标

- 提示选择率：`hint_requested / failure`。
- 提示后的成功率：提示后成功次数 / 提示使用次数。
- 完整关卡完成率：完成第 3 回合人数 / 开始第 1 回合人数。
- 下一关率：开始下一完整关卡人数 / 完成上一关人数。

只有提示选择率和提示后成功率都证明价值，才值得接奖励视频。
